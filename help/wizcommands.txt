Wizard commands:

** Handling objects:

chmod	#ID [attributes] -- Sets objects attributes 
chown	#ID [new owner]	 -- Changes objects owner
create	[name]		 -- Creates an object
delete	#ID		 -- Deletes an object
move	#ID [location]	 -- Moves an object
rename	#ID [new name]	 -- Renames an object

** Handling rooms:
dig			-- Creates a new room

			-- Sets a room's exit
setexit #ID [direction] #TargetID

** Handling users:
kill	[user]				-- Kills a person. ARCHWIZARD+ ONLY
kick	[user]				-- Kick user off MUD server
force	[user] [command]		-- Force user to perform command
gag	[user]				-- Gag a user
ungag	[user]				-- Ungag a user
ban	[IP address]			-- Ban IP address
unban	[IP address]			-- Unban IP address
take	[object name]			-- Take object from user
setrace	[user] [race]			-- Set user race
sethome	[user] #ID			-- Set user home room
setgender [user] [gender]		-- Set user gender
setlevel [user]	[level]			-- Set user level
setclass [user]	[class]			-- Set user class
setxp [user] [number of points]		-- Set user experience points
setmp [user] [number of points]		-- Set user magic points
setsp [user] [number of points]		-- Set user stamina points

					-- List banned IP addresses
listbans {IP address regular expression}

** Adding new types:
					-- Creates a new monster
addmonster	[name] [description] [stamina] [damage] [class]

					-- Adds a new weapon
addweapon	[name] [description] [damage]	[level] [class]

					-- Add a new spell
addspell	[name] [description] [message] [points] [damage] [level] [class]

					-- Add a new race
addrace	[name] [magic] [strength] [agility] [luck] [wisdom] [intelligence] [stamina]

					-- Add a new class
addclass	[name]

** Communication:
wall	[message]			-- Send message to all connected users

** Concealment:
invisible 				-- Go invisible
visible 				-- Go visible

** Movement:
go	#room_number			-- Teleport to location

** Handling monsters:
banishmonster				-- Banish monster in room

** Handling configuration:
reload					-- Reload configuration and database. ARCHWIZARD+ ONLY

** system:
shutdown				-- Shutdown system. ARCHWIZARD+ ONLY
